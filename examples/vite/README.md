# multi-layer-radial-chart · Vite example

A minimal [Vite](https://vitejs.dev) + React 19 app that installs
`multi-layer-radial-chart` from npm and renders an interactive activity-ring
chart (with `onSegmentClick` + keyboard focus).

## Run locally

```bash
npm install
npm run dev
```
